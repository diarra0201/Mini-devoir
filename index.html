📚 FAQ Git & GitHub

Quelle est la différence entre Git et GitHub ?

Git est un outil local de gestion de versions. GitHub est une plateforme en ligne pour héberger et partager les projets Git.

À quoi sert git init ?

Il sert à créer un nouveau dépôt Git dans un dossier pour commencer le suivi des modifications.

Comment envoyer un projet sur GitHub ?

On utilise la commande git push pour envoyer les modifications vers GitHub.

Pourquoi utiliser les branches ?

Les branches permettent de travailler sur différentes versions sans toucher au projet principal.

Comment voir l’historique des commits ?

On utilise la commande git log pour afficher tous les commits.
